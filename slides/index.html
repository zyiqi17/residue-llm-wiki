一個複雜的積分，有時候只要知道函數在幾個「壞掉的點」附近長什麼樣子，就能直接寫出答案。

暖身

你已經會算的一個積分

∫−∞∞ 11 + x² dx = arctan x │−∞∞ = π2 − (−π2) = π

微積分課用反三角函數就能算出來。

今天的目標用一個完全不同的方法再算一次：不找反導函數，而是走到複數平面上繞一圈。

最後一頁之前，你會看到答案一樣是 π。

第一步

在複數平面上積分

微積分的 ∫ab f(x) dx 是沿著數線從 a 走到 b。

複數 z = x + iy 住在平面上，所以積分可以沿著平面上的任何路徑走，甚至繞一圈回到起點。

封閉曲線積分沿著一條封閉曲線 C 把 f(z)·dz 加起來，記作 ∮C f(z) dz。

預設方向是逆時針。

關鍵發現

繞原點一圈，只有 1/z 會「留下來」

沿著單位圓 |z| = 1 逆時針繞一圈，把各種 zⁿ 的封閉曲線積分算出來：

n−2−1012
被積函數1/z²1/z1zz²
∮ zⁿ dz02πi000

為什麼？代入 z = eiθ，只有 n = −1 時被積分的東西是常數 1，積出 2πi；其他情況都是 eikθ 繞一整圈，正負抵消成 0。

記住這張表：後面所有內容都是從這裡來的。

第二步

奇點：函數「壞掉」的地方

奇點函數沒辦法好好定義、會爆掉的點。例如 1/z 在 z = 0。

極點最常見的奇點：函數在那裡像 c(z − z₀)ⁿ 一樣爆掉，n 叫做階數。

1/z → 一階極點（又叫簡單極點）
1/z² → 二階極點，爆得更快

第三步

羅朗級數：在奇點旁邊把函數拆開

泰勒級數 a₀ + a₁z + a₂z² + … 只能處理「沒壞掉」的點。在奇點旁邊，需要再加上負次方：

羅朗級數f(z) = … + a₋₂(z − z₀)² + a₋₁z − z₀ + a₀ + a₁(z − z₀) + …

例：e1/(2z) = 1 + 12z + 18z² + …　→ 1/z 那一項的係數是 1/2

負次方的部分叫做「主部」，它記錄了函數在奇點附近爆掉的方式。

主角登場

留數：繞一圈後「剩下來的東西」

把羅朗級數代進封閉曲線積分，逐項積分，再看第 4 頁那張表：

∮ f(z) dz = ∮ ( … + a₋₂(z−z₀)² + a₋₁z−z₀ + a₀ + … ) dz = 2πi · a₋₁

留數 Res(f, z₀)= a₋₁，也就是 1/(z − z₀) 那一項的係數。

名字的由來：把造成爆掉的部分拿掉之後，剩下來的那個數。例如

zz² + 1 = 1/2z − i + 1/2z + i　⇒　Res(f, i) = 1/2

今天的定理

留數定理

∮C f dz = 2πi · Σ Res

Σ Res：把 C 裡面每個奇點的留數加起來，外面的不算。

條件：f 除了一些孤立的奇點以外都很正常；C 是逆時針的封閉曲線，而且不經過奇點。

直覺把 C 慢慢「捏小」，變成繞著每個奇點的小圓，每個小圓貢獻 2πi × 留數。外面的奇點完全不影響。

工具

怎麼算留數？「蓋住法」

在簡單極點 z₀ 附近，f(z) ≈ Az − z₀，留數就是 A。所以只要把 (z − z₀) 乘上去，再代 z = z₀：

Res(f, z₀) = limz→z₀ (z − z₀) f(z)

例f(z) = z(z − i)(z + i) 在 z = i：蓋住 (z − i)，剩下 zz + i，代 z = i 得 i2i = 1/2

例5i − 3z = −5/3z − i/3　→　在 z = i/3 的留數是 −5/3

高階極點和本性奇點有其他公式，今天先不談。

例題

算算看：∮|z|=2 5z − 2z(z − 1) dz

  1. 找奇點：分母是 0 的地方 → z = 0 和 z = 1
  2. 哪些在裡面？半徑 2 的圓把兩個都圍住了
  3. 算留數（蓋住法）
    z = 0：蓋住 z，剩 5z − 2z − 1 → −2−1 = 2
    z = 1：蓋住 (z − 1)，剩 5z − 2z → 31 = 3
  4. 留數定理：2πi × (2 + 3) = 10πi

完全不用參數化、不用真的積分。🐾

回到開頭

用留數算 ∫ dx/(1 + x²)

  1. 把 x 換成 z：f(z) = 1/(z² + 1)
  2. 實數線 [−R, R] 加上上半圓，湊成封閉曲線
  3. 裡面只有極點 i，蓋住法：Res = 12i
  4. 留數定理：2πi · 12i = π
  5. 半圓那段：函數約 1/R²、弧長約 R，乘起來約 1/R → 0

結果∫−∞∞ dx/(1 + x²) = π，和 arctan 算的一樣！

總結

三句話記住留數定理

  1. 繞一圈積分，只有 1/(z − z₀) 那一項會留下來 → 它的係數叫留數
  2. 封閉曲線積分 = 2πi × 裡面的留數總和
  3. 簡單極點用蓋住法算留數

⚠️ 常見錯誤① 把曲線外面的極點也算進去　② 順時針忘了加負號　③ 曲線剛好經過極點時，定理不能用
