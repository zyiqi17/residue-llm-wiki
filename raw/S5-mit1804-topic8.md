## 抽取筆記
- n 階極點：羅朗級數主部最高到 a₋ₙ/(z−z₀)ⁿ，a₋ₙ ≠ 0；n = 1 稱簡單極點。
- 極點附近 f(z) ≈ c/(z−z₀)ⁿ。
- 定義：Res(f, z₀) = a₋₁。直覺：羅朗級數逐項積分時，只有 a₋₁/(z−z₀) 這一項積分不為 0。
- 小圓繞 z₀ 一圈：∮ f dz = 2πi·Res(f, z₀)。
- 例 8.5：Res(e^{1/(2z)}, 0) = 1/2。
- 例 8.6：1/z³ + 2/z² + 4/z + 5 + 6z 在 0 的留數 = 4；cos z 在 0 留數 0；sin z / z 為可去奇點、留數 0。
- 例 8.7：z/(z²+1) = (1/2)/(z−i) + (1/2)/(z+i)，Res(i) = Res(−i) = 1/2。
- 例 8.8（警告）：−1/(z(1−z)) 在 1 < |z| 的展開不能拿來算 z = 0 的留數；留數必須用去心圓盤 0 < |z−z₀| < R 上的展開。
- 例 8.9：log(1+z) 在 −1 是分支點，不是孤立奇點，沒有留數。
- 簡單極點：Res = lim_{z→z₀} (z−z₀)f(z)；f = g/h、g(z₀) ≠ 0、h(z₀)=0、h'(z₀) ≠ 0 時 Res = g(z₀)/h'(z₀)。
- 例 8.11：Res(1/sin z, nπ) = 1/cos(nπ) = (−1)ⁿ。
- 例 8.12：1/(z(z²+1)(z−2)²) 在 0 的留數 = 1/4。
- n 階極點：f = φ(z)/(z−z₀)ⁿ，Res = φ⁽ⁿ⁻¹⁾(z₀)/(n−1)!。
- 例 8.15：sinh(z)eᶻ/z⁵ 在 0 的留數 = sinh(z)eᶻ 的 z⁴ 係數。⚠️ 抽取結果顯示講義寫 5/24，但抽取模型自行乘開級數得到 1/3 → 交給驗算節點判定（V08）。
- 例 8.16：同一函數在 z = 2（二階極點）留數 = −13/100。
- 留數定理（8.5）：f 在區域 D 除孤立奇點外解析，C 是 D 中不經過奇點的逆時針簡單封閉曲線 → ∮_C f dz = 2πi·(C 內部留數和)。證明：在每個極點挖小圓並加切口，切口互相抵消。
- 例 8.18：1/(z(z²+1)) 留數 Res(0)=1、Res(±i)=−1/2；只圍 i → −πi；圍 i 和 0 → πi；三個都圍 → 0。
- 例 8.19：∮_{|z|=2} (5z−2)/(z(z−1)) dz，Res(0)=2、Res(1)=3 → 10πi。
- 例 8.20：∮_{|z|=1} z² sin(1/z) dz，Res = −1/6 → −πi/3。
- 例 8.21：∮_{|z−2|=1} 1/(z(z−2)⁴) dz，0 在外面，Res(2) = −1/16 → −πi/8。
- 例 8.22：1/sin z 圍住 0, π, 2π：留數 1, −1, 1 → 2πi。
- 無窮遠留數：Res(f, ∞) = −Res((1/z²)f(1/z), 0)；例 8.23 得 Res(f,∞) = −5，∮_{|z|=2} = −2πi·Res(f,∞) = 10πi。⚠️ 抽取模型在這裡寫了「−(−5) = 5, hmm」的錯誤推論，講義本身是 −5 → 交給驗算（V11）。
