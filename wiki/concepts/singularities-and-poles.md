# 奇點與極點

> 奇點是函數「壞掉」的點；極點是最常見、最溫和的一種奇點：函數在那裡像 1/(z − z₀)ⁿ 一樣爆掉。

## 直覺

- 1/z 在 z = 0 爆掉；1/(z² + 1) 在 z = ±i 爆掉。這些點就是奇點。
- **孤立奇點**：奇點周圍一小圈內沒有別的奇點，函數在那一小圈（扣掉中心）都很正常 [S8]。
- 爆掉的「速度」決定極點的階數：像 1/(z − z₀) 是一階、像 1/(z − z₀)² 是二階 [S5][S8]。

## 正式內容

孤立奇點依羅朗級數的主部（負次方項）分三類 [S3][S5]：

| 類型 | 主部 | 例子 |
|---|---|---|
| 可去奇點 | 沒有負次方項 | sin z / z 在 0 [S5] |
| n 階極點 | 有限項，最高到 (z − z₀)⁻ⁿ | 1/z³ + 2/z² + 4/z + … 在 0 是三階極點 [S5] |
| 本性奇點 | 無限多項 | e^{1/z} 在 0 [S5] |

- n = 1 的極點叫**簡單極點** [S5][S8]。
- n 階極點附近 f(z) ≈ c/(z − z₀)ⁿ [S5]。
- 分子分母判斷法：sin z 在 0 是一階零點、z² 是二階零點，所以 sin z / z² 在 0 是一階極點 [S5]。
- 不是所有「壞點」都是孤立奇點：log(1 + z) 在 z = −1 是分支點，不是極點，**沒有留數** [S5]。

## 例子

- z/(z² + 1)：在 z = i 與 z = −i 各有一個簡單極點 [S5][S8]。
- 1/(z(z² + 1)(z − 2)²)：0、i、−i 是簡單極點，2 是二階極點 [S5]。

## 常見錯誤

- 把分支點（例如 log 的 −1）當成極點去算留數 [S5]。
