# 常見錯誤整理

> 各來源提醒過、最容易犯的錯，集中在這一頁。

## 直覺

- 大部分錯誤都來自三件事：**方向**、**哪些奇點在裡面**、**用了哪個展開**。

## 正式內容

| 錯誤 | 正確做法 | 來源 |
|---|---|---|
| 順時針曲線沒加負號 | 順時針 → −2πi Σ Res | [S8] |
| 把曲線外的奇點算進去 | 只算內部的（外部繞數為 0） | [S1][S5] |
| 用 \|z\| > 1 的展開讀 z = 0 的留數 | 留數要用 0 < \|z − z₀\| < R 的展開 | [S5] |
| 把分支點（log 的 −1）當極點 | 分支點不是孤立奇點，沒有留數 | [S5] |
| n 階極點公式忘了 (n − 1)! | Res = φ⁽ⁿ⁻¹⁾(z₀)/(n − 1)! | [S5] |
| 算實積分時連下半平面極點也加 | 選上半平面就只算上半平面 | [S6][S9] |
| cos 型積分直接用 cos z | 換成 e^{iaz} 再取實部 | [S9] |
