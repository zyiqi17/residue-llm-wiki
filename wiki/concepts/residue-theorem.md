# 留數定理（Residue theorem）

> 沿著封閉曲線的積分 = 2πi ×（曲線**內部**所有奇點的留數總和）。只要知道內部每個奇點的「一個數字」，就知道整個積分。

## 直覺

- 曲線內部如果沒有奇點，積分是 0（柯西定理）。
- 有奇點時，可以把曲線「捏小」，變成繞著每個奇點的小圓；每個小圓貢獻 2πi × 該點留數 [S5][S7]。
- 曲線外面的奇點**完全不影響**答案 [S1][S5]。

## 正式內容

- **定理** [S5][S7]：設 f 在區域 D 中除了孤立奇點外都解析；C 是 D 中的簡單封閉曲線，**逆時針**、**不經過任何奇點**。則

  ∮_C f(z) dz = 2πi · Σ（C 內部各奇點的留數）

- **證明想法** [S5][S7]：在每個內部奇點周圍挖一個小圓，再用細細的切口把小圓和 C 連起來。新的曲線內部沒有奇點，由柯西定理積分為 0；切口來回各走一次互相抵消，剩下的就是「C 的積分 = 各小圓積分的和」，而每個小圓積分 = 2πi × 留數。
- **一般形式** [S1]：曲線可以繞好幾圈，這時每個留數乘上繞數 n(γ, aₖ)：∮_γ f dz = 2πi Σ n(γ, aₖ)·Res(f, aₖ)。
- 它是[柯西積分定理與柯西積分公式](cauchy-integral-formula.md)的推廣 [S1][S4]。

## 例子

- **例 1（簡報主例題）** ∮_{|z|=2} (5z − 2)/(z(z − 1)) dz [S5][S7]
  - 奇點：0 和 1，都在 |z| = 2 裡面
  - Res(0) = (5·0 − 2)/(0 − 1) = 2；Res(1) = (5 − 2)/1 = 3
  - 答案 = 2πi(2 + 3) = **10πi** ✅V06
- **例 2：同一個函數、不同曲線** f = 1/(z(z² + 1))，Res(0) = 1、Res(±i) = −1/2 [S5][S7]
  - 只圍住 i → −πi；圍住 i 和 0 → πi；三個都圍住 → 0 ✅V17
- **例 3：本性奇點** ∮_{|z|=1} z² sin(1/z) dz = 2πi·(−1/6) = **−πi/3** [S5][S7] ✅V05
- **例 4：外面的奇點不算** ∮_{|z−2|=1} 1/(z(z − 2)⁴) dz：z = 0 在曲線外，只算 z = 2，Res = −1/16，答案 −πi/8 [S5][S7] ✅V07
- **例 5** 1/sin z 圍住 0、π、2π：留數 1、−1、1，答案 2πi [S5][S7] ✅V10
- **例 6** 1/(z² + 1)：只圍 i → π；兩個都圍 → 0 [S8] ✅V21
- **例 7（自我檢測，由例 1 延伸）** 把例 1 的曲線縮小成 |z| = 1/2：只剩 z = 0 在裡面，用例 1 算過的 Res(0) = 2 [S5][S7]，答案 = 2πi · 2 = **4πi** ✅V22
  - 這題用來確認讀者懂「外面的奇點不算」。

## 常見錯誤

- 把曲線**外面**的奇點也算進去 [S5]
- 曲線是順時針卻沒加負號 [S8]
- 曲線剛好經過奇點：定理不適用 [S5][S7]
