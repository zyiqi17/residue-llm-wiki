# 用留數算實積分

> 把實數線上的積分「加一段大半圓」變成封閉曲線，用留數定理算，再證明半圓那段趨近 0。

## 直覺

- 實數線是一條直線，本身不會繞圈，所以沒辦法直接用留數定理。
- 解法：在上半平面補一個半徑 R 的大半圓，湊成封閉曲線 [S6][S9]。
- 半圓為什麼會消失：以 1/(z² + 1) 為例，在半徑 R 的弧上函數大約是 1/R²，弧長大約 R，相乘大約 1/R，R → ∞ 時趨近 0 [S9]。

## 正式內容

**六步驟** [S9]（S6 有相同的五步驟版本）

1. 把 x 換成 z（解析延拓）
2. 補一段弧把路徑封閉
3. 用留數定理算封閉曲線的積分
4. 拆成「實軸那段 + 弧那段」
5. 證明弧那段 → 0
6. 解出實積分；被積函數有 cos、sin 時取實部或虛部

**有理函數的結論** [S6]：若分母次數 ≥ 分子次數 + 2，且實軸上沒有極點，則

  ∫_{−∞}^{∞} f(x) dx = 2πi × Σ（**上半平面**極點的留數）

（理由：|f| ≤ M/|z|^a 且 a > 1 時，弧上積分 ≤ πM R^{1−a} → 0 [S6]）

**cos、sin 型**：把 cos(ax) 換成 e^{iaz}（a > 0），選上半平面，因為那裡 e^{iaz} 會衰減；最後取實部 [S6][S9]。

**三角函數積分** ∫₀^{2π}：令 z = e^{iθ}，cos θ = (z + 1/z)/2、sin θ = (z − 1/z)/(2i)、dθ = dz/(iz)，變成單位圓上的積分 [S6]。

## 例子

- **例 1（簡報用）** ∫_{−∞}^{∞} dx/(1 + x²) [S9][S6]
  - 上半平面只有極點 i，Res = 1/(2i)
  - 答案 = 2πi · 1/(2i) = **π** ✅V12
  - 和微積分對照：∫ dx/(1 + x²) = arctan x，從 −∞ 到 ∞ 也是 π/2 − (−π/2) = π。兩種方法答案相同。
- ∫ dx/(1 + x²)² = π/2 [S6] ✅V13
- ∫ dx/(1 + x⁴) = π/√2 [S6] ✅V14
- ∫ cos x/(4x² + 1) dx = π/(2√e) [S9] ✅V15
- ∫₀^{2π} dθ/(1 + a² − 2a cos θ) = 2π/(1 − a²)（|a| < 1）[S6] ✅V16

## 常見錯誤

- 下半平面的極點也算進去（選上半平面時只算上半平面）[S6][S9]
- 用 cos(az) 而不是 e^{iaz}：cos z 在上半平面不會衰減，弧不會消失 [S9]
