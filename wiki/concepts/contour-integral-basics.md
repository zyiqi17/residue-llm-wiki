# 複數路徑積分與最重要的積分 ∮ zⁿ dz

> 在複數平面上沿著一條封閉曲線把 f(z)·dz 加起來；繞原點一圈時，所有 zⁿ 裡只有 1/z 積出來不是 0。

## 直覺

- 微積分的 ∫ₐᵇ f(x) dx 是沿著實數線從 a 走到 b。複數的積分則是沿著平面上的一條**路徑**走，路徑可以繞圈。
- 本頁只需要記住一件事：**繞原點逆時針一圈**，zⁿ 的積分只有在 n = −1 時不是 0。這個「只有一項留下來」的現象，就是整個留數理論的起點 [S5][S8]。

## 正式內容

- 若 C 是以 z₀ 為圓心的逆時針圓，n 為整數，則 [S5][S8]

  ∮_C (z − z₀)ⁿ dz = 2πi（n = −1 時）；= 0（n ≠ −1 時）

- 理由（代入 z = z₀ + r e^{iθ}）：積分變成 i r^{n+1} ∫₀^{2π} e^{i(n+1)θ} dθ。n = −1 時被積分的是常數 1，得 2πi；其他 n 是一整個週期的 e^{ikθ}，積分為 0。
- 方向：逆時針是正方向；順時針時結果要變號 [S8]。
- 繞數（winding number）：曲線繞某點幾圈。逆時針簡單封閉曲線對內部的點繞數為 1、外部為 0 [S1]。

## 例子

- ∮_{|z|=1} dz/z = 2πi ✅V01
- ∮_{|z|=1} 1 dz = ∮ z dz = ∮ z² dz = ∮ dz/z² = 0 ✅V02

## 常見錯誤

- 忘記方向：順時針繞一圈得到 −2πi [S8]。
