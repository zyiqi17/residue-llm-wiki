# 怎麼計算留數

> 簡單極點用「蓋住法」或 g/h'；高階極點用導數公式；本性奇點只能展開級數。

## 直覺

- 簡單極點附近 f(z) ≈ A/(z − z₀)，留數就是 A。所以把 (z − z₀) 乘上去、讓 z → z₀，就能把 A「抓出來」[S8][S5]。

## 正式內容

| 情況 | 公式 | 來源 |
|---|---|---|
| 簡單極點 | Res(f, z₀) = lim_{z→z₀} (z − z₀) f(z) | [S2][S5] |
| f = g/h，g(z₀) ≠ 0、h(z₀) = 0、h'(z₀) ≠ 0 | Res(f, z₀) = g(z₀) / h'(z₀) | [S2][S5] |
| n 階極點，f = φ(z)/(z − z₀)ⁿ | Res(f, z₀) = φ⁽ⁿ⁻¹⁾(z₀) / (n − 1)! | [S5] |
| 本性奇點 | 沒有公式，只能展開羅朗級數讀 a₋₁ | [S2] |

- 用 lim (z − z₀) f(z) 判斷：極限不存在 → 本性奇點；= 0 → 解析或可去；= ∞ → 階數大於 1 [S2]。
- 高階極點通常直接展開級數比較快 [S2]。

## 例子

- 5/(i − 3z) = (−5/3)/(z − i/3)，Res = −5/3 [S8] ✅V19
- 1/sin z 在 nπ：g = 1、h = sin z、h' = cos z，Res = 1/cos(nπ) = (−1)ⁿ；例如 Res(1/sin z, π) = −1 [S5] ✅V10
- 1/(z(z² + 1)(z − 2)²) 在 0：Res = 1/4 [S5] ✅V18
- 同一函數在 z = 2（二階極點）：φ = 1/(z(z² + 1))，Res = φ'(2) = −13/100 [S5] ✅V09
- sinh(z)eᶻ / z⁵ 在 0（五階極點）：留數 = sinh(z)eᶻ 的 z⁴ 係數 = **1/3** ✅V08
  - ⚠️ **來源衝突**：S5 的抽取筆記顯示講義寫 5/24。用 sinh(z)eᶻ = (e^{2z} − 1)/2 可得 z⁴ 係數 = 2⁴/(2·4!) = 1/3，數值驗算 V08 也得到 1/3。Wiki 採用 1/3（可能是講義或抽取時的錯誤）。

## 常見錯誤

- n 階極點的公式忘了除以 (n − 1)!，或只微分一次 [S5]。
- 在 g(z₀) = 0 時套 g/h'（那時可能根本不是極點）[S5]。
