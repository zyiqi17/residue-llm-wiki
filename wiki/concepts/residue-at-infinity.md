# 無窮遠處的留數

> 進階技巧：把「曲線外面」當成內部，有時只要算一個留數就能取代很多個。

## 直覺

- 曲線把平面分成裡面和外面。所有留數（含無窮遠）加起來是 0，所以「裡面的總和」= −「無窮遠的留數」[S2][S5]。

## 正式內容

- 定義：Res(f, ∞) = −(1/2πi) ∮_C f dz，C 是圍住所有有限奇點的逆時針曲線 [S5]
- 計算：Res(f, ∞) = −Res((1/z²) f(1/z), 0) [S5]
- 全平面只有有限個奇點時：所有有限留數 + Res(f, ∞) = 0 [S2][S5]

## 例子

- f = (5z − 2)/(z(z − 1))：(1/z²) f(1/z) = (5 − 2z)/(z(1 − z))，在 0 的留數 = 5，所以 Res(f, ∞) = −5 [S5] ✅V11
  - 檢查：有限留數 2 + 3 = 5，加上 −5 = 0 ✔
  - ⚠️ **抽取錯誤紀錄**：S5 抽取筆記中，抽取模型寫了「−(−5) = 5」的錯誤推論；講義本身是 −5。驗算 V11 確認 −5。

## 常見錯誤

- 忘記前面的負號 [S5]
